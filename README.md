# Mochi 酒馆互通 · 测试版

在酒馆「扩展 → 安装扩展」粘贴 `https://github.com/gugugudaxi-sketch/mochi-tavern-bridge`，完成后刷新酒馆。

服务端仅首次安装需要在 Termux 的酒馆根目录运行一次下面的命令，然后重启酒馆：

```sh
node "$(find data public/scripts/extensions/third-party -name install-server.mjs -path '*/mochi-tavern-bridge/*' -print -quit)"
```

脚本会安装本机通信插件并开启服务端插件选项，保留原配置备份和已有配对/记忆。以后更新扩展后，如服务端也有更新，可重跑此命令。

重启后：酒馆扩展复制配对码 → Mochi设置「酒馆互通」填写 http://127.0.0.1:18181 和配对码 → 保存并测试 → 回酒馆刷新角色列表并绑定。

只互通最近文字，不导入面具、角色卡或世界书。支持手动和前台自动同步。测试版，需 Android APK 与同手机 Termux 酒馆配合使用。


## 0.2 更新：长期记忆与经历保存

需要 Mochi v3.2.4。更新扩展后，请重新运行上面的服务端安装命令并重启酒馆；会保留已有配对与存档。

- 读取Mochi已保存的日度/月度记忆、宫殿活节点/事件盒摘要和门牌，按绑定面具与角色隔离。角色卡、人设、世界书各自保留。
- 酒馆显示同步记忆总数与本轮实际注入数，注入字符上限默认30000，可调整。不是宫殿实时检索。
- 新增线下经历先送到Mochi持久待确认列表。在Mochi互通面板预览编辑正文与剧情日期，确认后永久保存，可从见面记录查看，作为现有记忆归档材料。不会自动付费总结或直接向量化。
- 实际同步时间单独保留，剧情日期不会改写真实收发时间；已保存经历不被远端编辑静默覆盖。
- 传输上限：保存记忆10000项/50万字符，近期原文1～100条，超过6万字符自动分批（每批不超过5万字符），整次最多200万字符。超限明确报错，不静默截掉后宣称全量同步。


## 0.2.1 设置直接保存

调整同步条数（1～100）、自动同步或长期记忆注入字符上限（1000～500000）后，点击「保存当前设置」。原绑定ID、消息标识、接收回执和记忆副本保留，无需解绑；界面区分未保存修改和已生效设置。

本次首次升级需重新运行服务端安装脚本并重启酒馆，以加载新增的设置保存接口。Mochi APK不需更新。此后日常调整设置直接点保存即可。


## 0.2.2 原文自动分批

选中范围内原文超过6万字符时自动分批上传，每批正文最多48000字符；单条超长消息也拆成分片，保持emoji完整。服务端验证分片数量与原文长度，全部收齐后一次提交完整原文，不把半段写入待确认列表。界面显示批次进度。

网络请求失败最多自动重试3次；重复分片和提交不会重复增加经历。仍然失败时保留旧同步记录，原聊天不变，可再次手动推送；服务端重启导致未完成分片丢失时重新上传即可。最近1～100条的选区设置不变，不会自动扫描整个历史存档。每次总原文及未接收队列仍受200万字符上限保护，超出明确报错，不静默截断。

本次需更新扩展并重跑一次服务端安装脚本、重启酒馆，原配对与记录保留。Mochi APK无需重新打包。

## 0.3.0 测试版：时间感知与自填格式

先安装新版 Mochi APK，再更新此扩展并重跑一次服务端安装命令、重启酒馆。已有配对码、绑定和确认保存的经历保留，无须解绑。此次改动包含服务端；只刷新网页不够。

在当前绑定下填写「清除格式」，每行一对标签，例如：

```text
<think></think>
<thinking></thinking>
<details></details>
<disclaimer></disclaimer>
```

规则默认空白，由用户选择。不自动套用酒馆正则，不调用总结 API。匹配标签及整块内容被删除；普通未选择的标签/正文保留。支持嵌套、标签属性、大小写。`<details></details>` 删除所有折叠块，包括可能放在其中的剧情；请先「预览清理效果」。缺失结束标签清理到文末，孤立结束标签仅去掉标签自身。对 disclaimer 另兼容 `<>CONTENT AUTHORIZATION PROTOCOL MAINTAINED: ... </disclaimer>`，保留声明前的正文。原酒馆消息不改动。

操作顺序：填写规则 → 预览 → 保存当前设置 → 重新同步并清理 → 到 Mochi 同步新内容并预览待保存经历。

- **同步新内容**：正常收发当前设置范围的消息；重复原文沿用来源 ID/版本去重。
- **重新同步并清理**：重新清理本绑定服务端已有的同步副本并发送，更新未确认版本；纯格式空正文移除对应待确认条目。已确认经历、原聊天和其他绑定不改动。Mochi 中也提供此按钮，可直接请求并接收。历史副本合计超过200万字符时拒绝整批重发并保留原数据。
- 此功能不会抓取从未同步的整份酒馆存档；无法还原此前已经清除的格式文字。未确认编辑框若已打开，请重新点「预览并编辑待保存经历」加载新内容。

时间感知每次非预览生成前刷新，无额外 API：

- **沿用剧情**（默认）：保持正文最后明确的日期、时间、地点，不按实际同步时刻跳时。
- **跟随现实**：当前日期、星期、时间按最近 Mochi 同步的角色时区计算，未收到时区时使用浏览器设备时区；线上最近文字的实际发送时刻（线上时间感知开启才共享）与上次酒馆生成请求的实际间隔分别标识。Mochi 线下时间感知关闭时退回沿用剧情。网络断开仍可更新现实钟表，时区采用最后同步值。
- **关闭**：移除本扩展的时间提示，无法删除正文、其他扩展或已有总结中本来就包含的日期。

现实时间和虚构剧情日期独立；明确剧情优先，不推测空白期间发生了什么。此提示帮助模型衔接，不保证模型始终遵从，也不覆盖酒馆其他总结插件。

## 从 Mochi 直达绑定存档

打开对应角色的「＋ → 酒馆互通 → 打开绑定的酒馆存档」。保持 Termux 的酒馆运行，并在系统浏览器登录与绑定一致的酒馆账号。网页地址默认 `http://127.0.0.1:8000`，自定义端口时在 Mochi 互通设置中修改并保存。原有绑定可直接使用。此入口需要新版 Mochi APK 和 0.3.1-beta 扩展，可沿用 0.3.0-beta 服务端。若酒馆先显示登录页，登录后从 Mochi 再点一次入口。
